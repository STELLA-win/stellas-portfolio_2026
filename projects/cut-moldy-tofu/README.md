# 切霉豆腐

一个由中文双关驱动的 Web 互动小游戏。用户通过滑动屏幕切掉焦虑、内耗与生活中的小倒霉。

本目录是现有 Cloud Run 版本的 GitHub Pages 独立发布版。它使用原生 HTML、CSS 与 Canvas JavaScript 实现，不依赖服务端或第三方运行时，因此可以在仓库子目录中直接运行。

## 功能

- 30 秒切割回合
- 鼠标、触屏与手写笔输入
- 快速滑动线段碰撞检测
- 豆腐抛物线、分裂、粒子、连斩和音效反馈
- 好运误切提示、去霉报告、重玩与网页分享
- 高分屏与移动端适配

## 本地预览

在本目录启动任意静态文件服务器，例如：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000`。
